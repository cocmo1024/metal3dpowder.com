# SEO audit - 2026-05-05

Goal: keep the stable version lean, crawlable, and inquiry-oriented. This audit focused on technical SEO, structured data, sitemap quality, internal links, and real redundancy.

## Sources checked

- Google Search Central SEO Starter Guide: https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- Google Search Central helpful content guidance: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- Google Search Central product snippet structured data: https://developers.google.com/search/docs/appearance/structured-data/product-snippet
- Google Search Central sitemaps overview: https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview
- Google Search Central robots meta tag docs: https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag

## Checks performed

- Canonical URLs: present across core pages, blog archives, tag archives, hubs, and article pages.
- Robots handling: tag archives already use `noindex,follow`; paginated blog archives now also use `noindex,follow`.
- Sitemap quality: tag archives were already excluded; paginated blog archive URLs are now excluded because they are crawl paths, not valuable search landing pages.
- Structured data: article pages use BlogPosting and breadcrumbs; FAQ uses FAQPage; content hubs use CollectionPage. Homepage multi-product Product/Offer markup was removed because the page is a catalog, not a single-product detail page.
- Internal links: no broken internal content links found in source-level scan.
- Content duplication: no duplicate titles, duplicate descriptions, or exact repeated long paragraphs were found across 90 articles.
- Thin content: no article below the local minimum review threshold was found.
- Redundancy: removed unused site fields and the unused external font dependency.

## Actions taken

- Removed homepage multi-product `Product` / `Offer` structured data while keeping visible product cards, pricing, particle size, lead time, and CollectionPage schema.
- Set `/blog/page/*/` pages to `noindex,follow,max-image-preview:large`.
- Excluded `/blog/page/*/` from sitemap output.
- Removed unused `@fontsource-variable/space-grotesk` dependency and unused `siteInfo` fields.
- Removed the nonessential generator meta tag from the shared layout.

## No-change decisions

- Kept tag archives generated but noindexed. They support user navigation from article tags without being promoted in the sitemap.
- Kept supplier-related content because the current page is product/specification focused and Search Console history previously showed supplier intent. It was not generic procurement content.
- Kept Contact and FAQ conversion blocks because they support RFQ clarity and do not create duplicate indexable pages.
- Kept current article set because the audit found no duplicate titles, duplicate descriptions, exact paragraph duplication, or genuinely thin pages.
